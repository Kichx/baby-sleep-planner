# История изменений

Короткие заметки для тестеров и владельца продукта. Пишите здесь только то, что помогает понять, зачем ставить новый APK и что проверить.

Формат версии: `app.version (Android versionCode)`, например `1.0.1 (11)`.

## Следующий релиз

### Что изменилось
- Добавлена подготовка релизного процесса: checklist, release record template и заметки в `AGENTS.md`.
- Добавлен вывод версии приложения на экране "Справка".
- Обновлены Expo SDK 56 patch-зависимости до версий, которые проходит `expo-doctor`.

### Что проверить
- Экран "Справка" показывает версию приложения.
- `npm run verify` проходит перед Android preview build.
- Новый APK после сборки имеет ожидаемый `versionCode`.

### Известные ограничения
- Android-уведомления и native/inline module поведение считаются полностью проверенными только после установки APK на устройство.
