# Release Records

В этой папке хранятся карточки важных Android preview APK. Они нужны, чтобы быстро понять, какой APK установлен у тестера, что изменилось и какие проверки уже были сделаны.

Для нового релиза:

1. Скопировать `_template.md`.
2. Назвать файл в формате `YYYY-MM-DD-vX.Y.Z-build-N.md`.
3. Заполнить ссылки на EAS build и APK.
4. Коротко описать изменения и smoke-check.

Не записывайте сюда секреты, signing details, raw database contents или приватные локальные пути.
