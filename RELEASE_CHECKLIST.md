# Release Checklist

Используйте перед каждым важным Android preview APK. Цель — чтобы у каждого билда было понятно: что изменилось, что проверено и где найти APK.

## Перед сборкой

- [ ] Проверить `git status --short --branch`.
- [ ] Убедиться, какие uncommitted изменения должны попасть в APK.
- [ ] Обновить `CHANGELOG.md`.
- [ ] Поднять `expo.version` в `app.json`, если это новый пользовательский релиз, а не технический rebuild.
- [ ] Подготовить короткий EAS message из версии и changelog summary.
- [ ] Запустить `cmd /c npm run verify`.

## Сборка

- [ ] Запустить build с коротким сообщением:

```bat
cmd /c npm run eas:build:android:preview -- --message "1.0.1: short release note"
```

- [ ] Не запускать второй build, если первый долго стоит в `IN_QUEUE`; мониторить существующий build id:

```bat
cmd /c npm run eas:build:view -- <build-id> --json
```

## После сборки

- [ ] Получить финальный JSON: `cmd /c npm run eas:build:view -- <build-id> --json`.
- [ ] Записать EAS build URL.
- [ ] Записать APK URL, если ссылка нужна для быстрой установки.
- [ ] Записать `versionCode`.
- [ ] Создать release record по шаблону `docs/releases/_template.md`.
- [ ] Если это успешный пользовательский релиз, перенести `## Следующий релиз` в `CHANGELOG.md` в секцию `## <version> (<versionCode>) — <YYYY-MM-DD>` и создать новый пустой `## Следующий релиз`.
- [ ] Если build failed/canceled, оставить `CHANGELOG.md` в `Следующий релиз` и создать release record со статусом ошибки.

## Android smoke-check

- [ ] APK устанавливается и запускается.
- [ ] Экран "Справка" показывает ожидаемую версию и build number.
- [ ] Старт сна создаёт или обновляет активное уведомление.
- [ ] Время сна в уведомлении меняется в фоне.
- [ ] Завершение сна убирает уведомление.
- [ ] Ручной ongoing sleep показывает или обновляет уведомление.
- [ ] Удаление или редактирование активного сна убирает или обновляет уведомление.
- [ ] Отказ в разрешении уведомлений не ломает логирование сна.
- [ ] После перезапуска приложения локальные данные и активный сон синхронизируются корректно.
